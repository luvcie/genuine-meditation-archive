# Intention Before Sitting

**r/genuinemeditation** · by **refugeinbuddha** · *(OCR)* · *परमानन्द Paramananda* · `Advice` · 5 points · 1 year ago

Before one sits down to meditate, it is useful to set the intention for the meditation. For some, it can be useful to repeat the Bodhisattva vow that you have made.

Do this before every sit, and you will realize that your sits will become more fruitful.
